## How to add a piece

1. Create `my_writings/<short-slug>.md` — lowercase, hyphens, no dates in the filename.
2. Give it the standard footer: `[← My Writings](README.md) | [← Home](../README.md)`
3. Add a row to the table above and bump the count in the banner.
4. Do **not** add a row to `history.md` — that file is for links collected from elsewhere.

Pieces are **not** cross-linked into `topics/` for now. The table above is the single way in, which keeps the topic pages about collected material. Worth revisiting once there are enough pieces that browsing by subject beats scanning this list.

A piece is free-form; there is no required template. If it grew out of a specific problem, the **Problem / Observation / Approach / Result** shape used in [topics/gpu/optimization.md](../topics/gpu/optimization.md) is a good starting point.

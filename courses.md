# Courses

Online courses, certifications and structured learning paths.

## AI / LLM

### RAG

- [Advanced RAG with Vector Databases and Retrievers — IBM](https://www.coursera.org/learn/advanced-rag-with-vector-databases-and-retrievers) — Coursera; FAISS and Chroma DB with LangChain and LlamaIndex retrievers
- [Advanced Retrieval Augmented Generation for Production — LlamaIndex × Activeloop](https://www.llamaindex.ai/blog/join-thousands-in-our-free-advanced-rag-certification-created-with-activeloop-ad63f24f27bb) — Free certification; 40+ lessons and 7 projects using LlamaIndex and Deep Lake across legal, biomedical, e-commerce and finance
- [Advanced RAG — CampusX](https://learnwith.campusx.in/courses/Advanced-RAG-69d8037290a183fe36833265#tableofcontents) — Hands-on, production-grade RAG with LangChain, LangGraph and vector databases
- [Advanced RAG Techniques: Choosing the Right Approach — Educative](https://www.educative.io/courses/advanced-rag-techniques) — Pre-retrieval indexing and query formulation, then RAG-Fusion and cross-encoder reranking
- [Retrieval Augmented Generation (RAG) — DeepLearning.AI](https://www.deeplearning.ai/courses/retrieval-augmented-generation) — Zain Hasan; the longest of these at ~26 h over 5 modules, 49 lessons and 9 code examples — the one to use as the backbone
- [Advanced RAG With Pinecone — ADaSci](https://adasci.org/courses/advanced-rag-with-pinecone) — RAG built on the Pinecone managed vector database

### Agents

- [CS329A: Self-Improving AI Agents — Stanford (Aakanksha Chowdhery & Azalia Mirhoseini)](https://cs329a.stanford.edu/#intro) — Free Stanford course on agents that improve themselves through interaction: constitutional AI, verification systems, RL, test-time compute scaling, multi-step reasoning, tool use, and eval frameworks for agentic workflows

- [Agentic AI Bootcamp: Build Autonomous AI Systems in 3 Days — School of AI](https://www.udemy.com/course/agentic-ai-bootcamp-build-autonomous-ai-systems-in-3-days/) — Udemy; ~4 h over 22 lectures: the ReAct loop, then multi-agent systems with LangGraph, CrewAI and AutoGen, then evaluation, guardrails and observability, ending in a production-style multi-agent capstone
- [GenAI and Agentic AI BootCamp: 14+ Projects, 8 Capstones — AgileFever](https://agilefever.com/bootcamps/agentic-ai-bootcamp/) — Instructor-led paid bootcamp; 74 h over 8 weeks (64 live + 10 self-paced) for experienced IT professionals: GenAI, RAG, multi-agent architectures and cloud deployment on Azure, AWS and GCP
- [Building AI Agent Harnesses with Strands Agents — Amazon Web Services (Morgan Willis)](https://www.coursera.org/learn/build-ai-agents) — Coursera; beginner, ~6 h self-paced over 5 modules: the agent loop and MCP tools, hooks/plugins/skills/steering, context and memory management, multi-agent orchestration (agents-as-tools, graphs, swarms), then evaluation and deployment to Amazon Bedrock AgentCore

## GPU / Performance

- [LLM Inference Optimization — Rishabh Misra (Udacity)](https://www.udacity.com/course/llm-inference-optimization--cd14455) — Udacity (Accenture); intermediate, ~11 h: faster generation via KV caching, GQA and Flash Attention, then quantization, pruning, speculative decoding and multi-device serving, ending in a news-headline-generator project

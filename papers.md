## To Read

- [ ] [Chain-of-Thought Prompting Elicits Reasoning in Large Language Models — Jason Wei et al.](https://arxiv.org/abs/2201.11903) — Step-by-step reasoning in the prompt, the foundation every agent builds on *(AI / LLM)*
- [ ] [ReAct: Synergizing Reasoning and Acting in Language Models — Shunyu Yao et al.](https://arxiv.org/abs/2210.03629) — The reason-then-act loop that powers most agent frameworks today *(AI / LLM)*
- [ ] [Toolformer: Language Models Can Teach Themselves to Use Tools — Timo Schick et al.](https://arxiv.org/abs/2302.04761) — LLMs learn to call APIs on their own — kicked off the tool-use era *(AI / LLM)*
- [ ] [Generative Agents: Interactive Simulacra of Human Behavior — Joon Sung Park et al.](https://arxiv.org/abs/2304.03442) — Simulates 25 agents living in a town and shows emergent social behavior *(AI / LLM)*
- [ ] [Reflexion: Language Agents with Verbal Reinforcement Learning — Noah Shinn et al.](https://arxiv.org/abs/2303.11366) — Agents learn from verbal self-feedback instead of weight updates *(AI / LLM)*
- [ ] [Tree of Thoughts: Deliberate Problem Solving with Large Language Models — Shunyu Yao et al.](https://arxiv.org/abs/2305.10601) — LLMs explore and backtrack across reasoning paths like a search tree *(AI / LLM)*
- [ ] [HuggingGPT: Solving AI Tasks with ChatGPT and its Friends in Hugging Face — Yongliang Shen et al.](https://arxiv.org/abs/2303.17580) — Turns an LLM into a controller that picks and runs other AI models *(AI / LLM)*
- [ ] [Voyager: An Open-Ended Embodied Agent with Large Language Models — Guanzhi Wang et al.](https://arxiv.org/abs/2305.16291) — Lifelong-learning agent that explores Minecraft and writes its own skill library *(AI / LLM)*
- [ ] [AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation — Qingyun Wu et al.](https://arxiv.org/abs/2308.08155) — Multi-agent conversation framework behind Microsoft's AutoGen library *(AI / LLM)*
- [ ] [A Survey on Large Language Model based Autonomous Agents — Lei Wang et al.](https://arxiv.org/abs/2308.11432) — Maps the whole field into construction, application and evaluation *(AI / LLM)*

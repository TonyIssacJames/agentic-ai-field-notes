# Articles

Articles, blog posts, Medium posts, documentation pages, and papers worth reading.

## To Read

- [ ] [AI Evals: Art and Science of Building Reliable AI Apps](https://arshren.medium.com/ai-evals-art-and-science-of-building-reliable-ai-apps-11dbfba2a343) — Evaluating LLM apps for reliability; from [Renu's blog](blogs.md)
- [ ] [Prompting Techniques — Agentic Engineering Guide](https://agentic-engineering.swmansion.com/becoming-productive/prompting-techniques/) — Software Mansion's tactics for steering coding agents: scoping tasks upfront, correcting mid-run, multimodal input
- [ ] [Harness Engineering — Agentic Engineering Guide](https://agentic-engineering.swmansion.com/becoming-productive/harness-engineering/) — Improving agent output by shaping its environment (config files, skills, MCP servers, subagents, hooks) instead of only the prompt
- [ ] [Ultraprompting: How The World's Top Prompt Engineer Triggers Thousands Of Agents With One Prompt](https://blockbuster.thoughtleader.school/p/ultraprompting-how-the-worlds-top) — Michael Simmons on how top users like Boris Cherny get multi-week outcomes from single, well-structured prompts (dynamic workflows, clear goals, feedback loops)
- [ ] [Improving skill-creator: Test, measure, and refine Agent Skills](https://www.linkedin.com/pulse/improving-skill-creator-test-measure-refine-agent-skills-paul-petri-gogxf/) — Paul Petri builds a multi-agent workflow with six specialized agents, evaluated with Anthropic's eval tools (100% quality with the skill vs. 73% without); frames a way to measure capability uplift vs. encoded preference
- [ ] [Building Effective AI Agents](https://www.anthropic.com/engineering/building-effective-agents) — Anthropic's engineering guide: favor simple, composable patterns (prompt chaining, routing, autonomous agents) over complex frameworks, and only add complexity when measurements justify it; presented as a [talk](youtube.md) by Barry Zhang
- [ ] [10 RAG Shifts Redefining Production AI in 2026 — Ozgur Guler](https://medium.com/microsoft/10-rag-shifts-redefining-production-ai-in-2026-7acbdd66076c) — Microsoft Azure on Medium; what separates functional RAG from production-grade RAG — treating retrieval misses as coverage failures rather than ranking ones, and combining retrievers with different failure modes (dense + BM25, vector + graph)
- [ ] [Loops and Graphs: how to stop babysitting agents and only approve the last step — Hanako](https://x.com/hanakoxbt/status/2091515787366306154) — Long-form post on X: the loop lives inside a node (produce, check, correct until it passes), the graph lives between nodes (what runs when, in parallel, on whose output); most people build the loop and skip the graph, then put human approval on intermediate steps instead of the last irreversible one
- [ ] [Graph Engineering: The Complete Guide to Building Multi-Agent AI Systems — Lunar](https://x.com/LunarResearcher/status/2086071302272528833) — Long-form post on X: designing the topology of a multi-agent system rather than the agents — order vs. real dependency, explicit typed state between nodes, budgeting parallelism, optimizing the critical path, adversarial verifiers, and human gates enforced by architecture rather than by prompt. Pairs directly with the Loops and Graphs post above
- [ ] [Claude Can Do All of This. Most People Have No Idea. — Anatoli Kopadze](https://x.com/AnatoliKopadze/status/2057813254617858078) — Long-form post on X: a tour of 17 Claude features across the product surface — Projects, Artifacts, extended thinking and memory; role-based prompting patterns; then Claude Code, Skills, `CLAUDE.md`, Cowork, Claude Design, scheduled tasks, the Chrome extension and prompt caching. A map of what exists rather than a deep dive; written May 2026, so check anything that looks dated

## AI / LLM

### RAG

- [Advanced RAG with Vector Databases and Retrievers — IBM](https://www.coursera.org/learn/advanced-rag-with-vector-databases-and-retrievers) — Coursera; FAISS and Chroma DB with LangChain and LlamaIndex retrievers
- [Advanced Retrieval Augmented Generation for Production — LlamaIndex × Activeloop](https://www.llamaindex.ai/blog/join-thousands-in-our-free-advanced-rag-certification-created-with-activeloop-ad63f24f27bb) — Free certification; 40+ lessons and 7 projects using LlamaIndex and Deep Lake across legal, biomedical, e-commerce and finance
- [Advanced RAG — CampusX](https://learnwith.campusx.in/courses/Advanced-RAG-69d8037290a183fe36833265#tableofcontents) — Hands-on, production-grade RAG with LangChain, LangGraph and vector databases
- [Advanced RAG Techniques: Choosing the Right Approach — Educative](https://www.educative.io/courses/advanced-rag-techniques) — Pre-retrieval indexing and query formulation, then RAG-Fusion and cross-encoder reranking
- [Retrieval Augmented Generation (RAG) — DeepLearning.AI](https://www.deeplearning.ai/courses/retrieval-augmented-generation) — Zain Hasan; the longest of these at ~26 h over 5 modules, 49 lessons and 9 code examples — the one to use as the backbone
- [Advanced RAG With Pinecone — ADaSci](https://adasci.org/courses/advanced-rag-with-pinecone) — RAG built on the Pinecone managed vector database
